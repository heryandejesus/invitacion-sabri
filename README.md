# Digital Birthday Invitation — Sabrina 🎉

Interactive digital birthday invitation with countdown timer, 
RSVP functionality, and animated responses.

## 🔗 Live Site

[invitacion-sabri.vercel.app](https://invitacion-sabri.vercel.app/)

## 📋 About

A personalized digital invitation built as a done-for-you service.
Guests can confirm attendance via an interactive RSVP with three response
options, each triggering a unique animated reaction.

## ✨ Features

- Live countdown timer to the event date
- Interactive RSVP (Yes / Maybe / No) with animated GIF responses
- Event details: date, time, and location
- Mobile-first responsive design
- Deployed on Vercel

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Deployed on [Vercel](https://vercel.com/)

## 💡 About This Project

This invitation is part of a digital invitation service offering 
personalized, interactive invitations for birthdays, weddings, and 
other events — as an alternative to traditional paper invites.
